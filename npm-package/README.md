# skyvex

Terminal installer for **SkyVEx** — an asset exporter GUI for *Sky: Children of the Light* (3D maps/models → OBJ, textures → PNG, audio → WAV).

> Windows only. Installing on macOS/Linux is blocked by npm (`os: win32`).

## Install

```
npm install -g skyvex
```

The GUI binary (~40 MB) ships inside the package — no extra download, no
post-install script. In mainland China, use an npm mirror for speed:

```
npm install -g skyvex --registry https://registry.npmmirror.com
```

## Run

```
skyvex
```

Launches the GUI and returns your terminal.
